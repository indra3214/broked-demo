# БРОКЕД · сайт

Лендинг и интерактивное демо БРОКЕД, единого окна управления инвестициями. Публикуется через GitHub Pages.

- `index.html` – лендинг. Заявки из форм (бета-тест, команда, партнёры) уходят в Google Таблицу через веб-приложение Google Apps Script, адрес задан в `GOOGLE_SCRIPT_URL`. Ссылки вида `#beta`, `#team`, `#partner`, `#invest` сразу открывают нужную форму.
- `demo/` – демо: путь клиента от регистрации до первой сделки. Работает целиком в браузере, сервер и база данных не нужны. Брокеры, бумаги, котировки и ключи вымышлены.
