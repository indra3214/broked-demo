# БРОКЕД · демо

Интерактивное демо БРОКЕД, единого окна управления инвестициями. Клиент проходит путь от регистрации до первой сделки: ставит приложение для ПК, подключает брокеров по API-ключам «только чтение», видит все счета в одном портфеле, выдаёт ключ на торговлю, покупает бумагу и делает ребалансировку.

Всё работает в браузере, сервер и база данных не нужны. Брокеры, бумаги, котировки и ключи вымышлены.

Открыть локально: `index.html` в браузере.
